# Followers Manager icon

Original artwork generated on 2026-10-26 using the built-in image generation tool for this project. No third-party source artwork was supplied. The retro X is a reference to the platform; this project is independent of X and not endorsed by it. FM stands for follower management.

- `icon-source.png`: full generated master, retained for future asset work.
- `icon-16.png`, `icon-32.png`, `icon-48.png`, `icon-128.png`: square PNG sizes derived with macOS `sips`, referenced by the extension manifest and toolbar action. Only these runtime PNGs are included in the distributable ZIP.

## Generation prompt

Use case: logo-brand. Asset type: square Chrome browser extension icon for Followers Manager. Create one finished icon only, no mockup or presentation sheet. Retro 1980s pixel-art computer utility emblem. A bold large ivory pixel-block letter X on a very dark navy square background, with a subtle offset cyan pixel shadow. Small but crisp block-pixel letters "FM" together in a warm amber rectangular badge at the lower right; FM means follower management. Exact text: X and FM only. Simple chunky geometric bitmap shapes, restricted palette, high contrast, clean hard edges, no gradients, no fine texture, no glow, no extra symbols. The main X should dominate and remain recognizable at 16 pixels, the FM badge should be readable at 48 and 128 pixels. Icon fills the square with a narrow consistent safe margin and a solid opaque dark background, no outer canvas margins. Straight-on flat graphic, no perspective, no physical objects, no watermark.
